# Landed Cost · 落地成本

Photo of a Yiwu supplier's delivery note → landed cost per piece in rand → wholesale price per bale.
A local open-weight vision model (Gemma 4 via Ollama) reads the table; code checks every number and does the maths.
Photos, prices and settings never leave the computer.

Work in progress for the DEV Hacktoberfest Open-Source AI Challenge, Week 2: Side Hustle.
